Ctrl+Arm · Grok Hackathon, Pavia

Trova

Ask for an object, in English or Italian, or show a photo. Trova finds it on the table and an xArm points at it. The same station can scan the object in 3D and write a line-clearance record that a person signs.

Grok returns structured JSON. Plain code checks it, converts pixels to millimetres, and moves the arm. Stop does not wait for a model.

Source Release 0.1.0 Scan video MIT licence

Run it

python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
cp .env.example .env
.venv/bin/python -m trova

Leave the API key empty and Trova runs in mock mode. No robot is required for the tests.

What is included

  • Find by words, speech, or a phone photo, then point.
  • Line clearance: what was added, removed, or moved, with an operator signature.
  • A 3D scan of the table, with preview and full meshes.
  • Safety box, a latched stop, and one motion at a time.
